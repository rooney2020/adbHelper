# 代码质量审查清单

> 此文件由 SKILL.md 在完整模式下引用。对每个变更文件按维度检查。

## 正确性

最高优先级——代码是否按预期工作：

| 关注点 | 典型症状 |
|--------|----------|
| 逻辑错误 | Off-by-one、条件反转、短路求值遗漏 |
| Null 安全 | 未判空直接调用、Optional 误用、空集合遍历 |
| 竞态条件 | 并发读写无同步、非原子的 check-then-act |
| 资源泄漏 | 未关闭的流/连接/Cursor、未注销的监听器 |
| 异常处理 | 吞掉异常（空 catch）、缺失 finally/try-with-resources |
| 类型安全 | 强转无 instanceof 检查、泛型擦除后的类型错误 |

## 性能

关注对用户可感知或系统负载有影响的问题：

| 关注点 | 典型症状 |
|--------|----------|
| N+1 查询 | 循环中逐条数据库/网络调用 |
| 主线程阻塞 | UI 线程做 I/O、数据库、密集计算 |
| 内存问题 | Bitmap 未回收、内部类持有 Activity 引用、大对象缓存无上限 |
| 低效算法 | O(n²) 可替换为 O(n)、重复遍历、无必要的深拷贝 |
| 缺失缓存 | 重复计算同一结果、重复解析同一配置 |

## 可维护性

影响长期演进和团队协作：

| 关注点 | 判断标准 |
|--------|----------|
| 命名 | 方法/变量名能否望文知义，是否与职责匹配 |
| 复杂度 | 单方法超 50 行、圈复杂度 > 10、嵌套 > 3 层 |
| 重复 | 相似逻辑出现 2+ 次且未抽取 |
| 死代码 | 未使用的 import、不可达分支、注释掉的代码块 |
| 耦合 | 跨层直接依赖、God Class、Feature Envy |

## 测试覆盖

检查改动是否有对应测试保障：

| 关注点 | 期望 |
|--------|------|
| 关键路径 | 核心业务逻辑有单元测试 |
| 边界值 | null、空集合、极值有对应 case |
| 错误路径 | 异常分支有测试覆盖 |
| Mock 隔离 | 外部依赖（网络/DB/系统服务）被 Mock |
| 断言质量 | 断言具体值而非仅"不抛异常" |

## 输出格式

| # | 文件:行号 | 类别 | 严重度 | 问题描述 | 建议 |
|---|-----------|------|--------|----------|------|
| 1 | path/File.java:L10 | 正确性 | High | Handler 匿名内部类持有 Activity 引用 | 改用 WeakReference 或静态内部类 |

严重度定义：
- **High** — 可能导致崩溃、数据丢失、严重性能问题
- **Medium** — 非致命但影响质量或后续维护
- **Low** — 代码坏味道，不紧急但值得改进
